## 🩵 Featured: Alzheimer's Voice Companion

**[alzheimer-companion](https://github.com/ssps6210/alzheimer-companion)** — 用家人的聲音陪伴失智長者 · A voice companion for people living with dementia.

Built for my own grandfather. The idea is simple: someone with Alzheimer's is far more likely to stay engaged with a voice they recognise, so the system speaks in a cloned family voice rather than a generic TTS one.

- 🎙️ **Voice cloning** so the companion sounds like family, not like a device
- 🧩 **Runs locally by default** — local LLM and local TTS, with a cloud fallback only when the machine can't keep up
- 🔁 **Swappable voice**, hot-reloaded without a restart, so a different family member can take over
- 🔒 **Recorded consent** required before any voice is cloned — a voice is biometric data, and it isn't the elder's to give away
- 🌏 Designed around Mandarin/Taiwanese-speaking elders, a group most voice assistants ignore
